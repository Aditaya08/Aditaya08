### What I'm building

**[ScriptScope](https://bitcoin-script-analyser-web.vercel.app)** — a Bitcoin Script debugger.
The execution engine is Rust compiled to WebAssembly, so ~75 opcodes step instruction by
instruction in the browser with no round-trip. An Axum API alongside it fetches and decodes
mainnet transactions with provider fallback. Eight Rust integration tests cover classification,
debugger flow and consensus limits. → [code](https://github.com/Aditaya08/Bitcoin_Script_Analyser)
